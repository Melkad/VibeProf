## Première professionnelle

- Cycle terminal : les notions et mots-clés déjà travaillés en seconde (signalés par un astérisque) sont réinvestis ; chaque thème met l'accent sur quatre capacités qui doivent être maîtrisées par les élèves.
- Analyse de documents attendue en première : comprendre le sens général d'un document ; situer le document dans un contexte, dégager le point de vue de l'acteur concerné ; dégager l'intérêt du document (que nous apprend-il sur la période étudiée ?).
- Récit : les compétences de récit historique sont réaffirmées en laissant plus de place à la production ; le professeur peut fournir un étayage pour les élèves fragiles, favoriser le travail collaboratif ou utiliser l'écriture relais.
- Tâche cartographique : s'entraîner à proposer une légende organisée, plus complexe.
